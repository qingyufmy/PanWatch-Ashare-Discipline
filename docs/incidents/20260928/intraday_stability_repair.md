## 修复

- FAST 使用 disabled thinking、JSON 格式、6000 输出预算、80 秒超时、零自动重试；DEEP 配置保留。迁移 143 保存模型 finish_reason、推理 token 数、正文长度与调用预算，不保存隐藏推理原文。空正文、截断、结构错误分别记录。
- 统一持仓批次在 09:45、10:00、10:15、10:30、10:45、11:00、11:15、13:15、13:30、13:45、14:00、14:15、14:30、14:45 运行。每次一个模型请求覆盖全组合；旧五分钟 intraday_monitor 在新工作流注册后退出。新增槽从部署激活时刻起核查漏跑，不补跑历史决策。
- 每分钟模拟扫描只处理每股最新、已生成、未过期信号；旧信号不因新信号 HOLD、被阻断或过期而重新生效。记录成交或跳过原因、模型/证据/政策/计划关联；继续限制 T+1、整手、资金、指数条件和仓位上限。
- 新组合提案替换旧当前决议，保留完整历史。界面区分具体操作提案、观察价触及、支撑破位及待核查方向。提案没有获得实盘批准；未知 HOLD 继续显示未核查。
- Lark 使用单次有界 HTTP 请求和供应商回执，风险通知最多五路并发，避免逐股串行拖住分钟风险任务。历史未知回执不重发，候选 Shadow 消息继续 SUPPRESSED。
- 盘中停止启动海外历史后验评估，减少与实时任务争用。运行状态接口与模拟盘页面展示最新批次、覆盖数、模拟成交和未成交原因。

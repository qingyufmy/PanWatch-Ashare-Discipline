# P2 信号与执行日志验收记录

## 结论

P2 的新建议追溯链、人工执行登记、T+1 待办和 REDUCE 部分减仓已在隔离工作区验证，并于 2026-09-22 部署到本地正式实例供人工审计。**本阶段尚未作为可执行生产信号发布**。隔离库升级到 v128/v129 后，一条新建议产生 1 条 SignalEvent、1 份冻结 EvidenceSnapshot 和 11 条政策裁决；读取 API 与新前端页面可以追溯。旧历史建议没有完整原始证据，不能宣称已实现全历史 100% 追溯。

## 实现与边界

- `save_suggestion` 对新建议在一个事务中写建议、冻结输入/模型输出、信号和裁决；失败时回滚。保留 TradingAgents 原始五档评级，映射为 OPEN / ADD / HOLD / REDUCE / EXIT。
- SignalEvent 保存 signal/trace ID、来源、计划和真相版本、有效期、语义去重键。状态变更只追加生命周期事件。
- 人工实际交易可以记录；若未通过政策门禁，明确记为 `USER_REPORTED_OUT_OF_POLICY` 和 `UNAUTHORIZED_ACTION`，不会伪装成系统批准。后续持仓快照仅做数量对账，匹配状态仍为 `QUANTITY_MATCHED_UNVERIFIED`。
- REDUCE 模拟盘只接受明确的部分数量或目标仓位，不能全平；相同触发信号重复扫描不重复减仓。EXIT 仍为全部退出。
- A 股新买入生成 T+1 待办；交易日历缺失则 `CALENDAR_REQUIRED`，不推测下一交易日。
- 新页面 `/discipline` 展示信号、政策、生命周期、人工执行；页面提交的是已发生交易的记录，不发券商订单。
